File Naming Guideline

To let the system know which character each PNG represents, name your files according to these standards:

  • Single Characters: Simply name the file as the character itself (e.g. A.png, z.png, 7.png, $.png). Case is preserved!
  • Unicode Format: Use prefix u followed by the hex codepoint (e.g. u0041.png for 'A', u0035.png for '5').
  • Raw Hex Format: Just name it with the 4-to-6 hex digits (e.g. 0041.png).
  • Alphanumeric tags: You can append suffix after an underscore (e.g. A_bold.png or u0041_alpha.png). The prefix before the first underscore is used for codepoint resolution.
